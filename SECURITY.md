# Security policy

## Supported version

Security fixes are applied to the latest version on the `main` branch.

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability.

Instead, use GitHub's private vulnerability reporting feature for this repository. Include:

- The affected route, table, or feature
- Steps to reproduce the issue
- The expected and observed authorization behavior
- Any proof-of-concept request with secrets removed
- Your assessment of impact

You should receive an acknowledgement within five business days.

## Scope

Useful reports include authentication bypass, cross-organization data access, Row Level Security mistakes, private file exposure, privilege escalation, token leakage, and unsafe API behavior.

Do not include real credentials, production user data, or destructive testing.
